# implementation-of-logistic-regression-Predicts whether a passenger survived the Titanic disaster using Kaggle’s dataset.
Full preprocessing pipeline includes missing value handling, feature engineering (FamilySize, IsAlone, Title), encoding, scaling, and skew correction.
Implemented Logistic Regression with train/test split and evaluation.
Accuracy: ~78–82%; key features: Sex, Pclass, Fare.
Pipeline is reusable for future ML experiments and model comparisons.
